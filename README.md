# Time Series Analysis of Crude Oil Prices
# 📌 Project Overview
The price of crude oil is essential to the economy because it is the driving force behind the energy sector, which supports transportation, electricity generation, and industrial production. This project analyzes gasoline and natural gas price dynamics across Canadian cities using Python-based exploratory and time-series analysis, identifying seasonal patterns, geographic differences, and trends to support data-driven insights and energy market monitoring.

# 🛠 Technical Approach
* Python for data cleaning, comparative analysis, and data visualization.
* Tableau for dashboard development and data storytelling
* Microsoft Excel and PowerPoint for Project reporting.
